Заголовок: contains возвращает True при передаче пустой строки и пустового символа, что противоречит логике и не задокументировано.
Шаги 
string_utilis = StringUtils()
assert string_utilis.contains("", "") == True # но ожидается False
Ожидаемый результат:
В документации должен быть описан этот случай. Логично предположить, что 
пустая строка не сожет содержать подстроку, поэтому должно быть False
Фактический результат:
Метод возвращает True
Приоритет: низкий
